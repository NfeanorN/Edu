Perfect Competition — Совершенная конкуренция

Источник: Robert H. Frank, Microeconomics and Behavior, 7th ed., Chapter 10 — «Competitive Supply» (стр. 305–321). Exam Prep Topic #15. Издержки (MC, AVC, ATC) — Ch. 9.

1. Что это? Условия Ch. 10 · Exam #15

Совершенная конкуренция — рынок с тысячами одинаковых мелких фирм. Каждая фирма — «капля в океане»: не может влиять на цену → price taker (ценополучатель).

Perfect competition: many identical small firms, homogeneous product, free entry and exit, perfect information. Each firm takes the market price as given.

Frank (Ch. 10): если фирма поднимет цену хоть на один цент — все покупатели уйдут к соседу. Цена «навязывается сверху» рынком.

2. Рынок vs одна фирма Ch. 10

Рыночный спрос D — нисходящий. Спрос для одной фирмы — горизонтальная линия на уровне P*: фирма может продать любой объём q по цене P*, но ничего не продаст, если поднимет цену.

Слева: равновесие рынка (P*, Q*). Справа: горизонтальный спрос фирмы — price taker.

3. P = MR = AR и правило P = MC Ch. 10

Общее правило любой фирмы: MR = MC. При конкуренции каждая доп. единица продаётся по той же цене P → MR = P = AR.

MR = MC  →  при конкуренции P = MR  →  P = MC

π = TR − TC = P·Q − TC. Фирма выбирает только q (P задана рынком).

  • P > MC → ещё одна единица увеличивает прибыль → производить больше
  • P < MC → ещё одна единица снижает прибыль → производить меньше
  • P = MC → оптимум q*

Produce while P > MC; stop where P = MC. Same MB = MC logic as Frank Figure 1.1.

Frank (Figure 10.2): рыночная цена P = $20. Горизонталь P = 20 пересекает MC при q* = 260 → фирма производит 260 единиц. Если P вырастет до $25 — точка пересечения сдвигается вверх по MC → q* больше.

Figure 10.2 (Frank): P = MC → q*. Если P > ATC — экономическая прибыль (зелёная область).

4. Краткосрочный период (SR) Ch. 10

K фиксирован. Возможны три случая:

P > ATCЭкономическая прибыль π > 0

Правило shutdown Ch. 10, p. 307

Работать, если P ≥ min AVC

Закрыться, если P < min AVC

В SR FC платятся в любом случае → вопрос: покрывает ли выручка хотя бы переменные издержки?

Frank — пекарня: FC = $1 000/мес, min AVC = $2/багет, min ATC = $4.
P = $3: 3 > AVC → работать. Каждый багет даёт $1 на FC. 500 багетов → убыток $500 (лучше, чем $1 000 при закрытии).
P = $1,50: 1,50 < AVC → закрыться. Убыток = FC = $1 000.

5. Долгосрочный период (LR) Ch. 10, p. 321

Свободный вход/выход:

  1. π > 0 → новые фирмы входят → S↑ → P↓ → π падает
  2. π < 0 → фирмы выходят → S↓ → P↑ → убытки сокращаются
  3. Процесс до π = 0

LR равновесие:   P = MR = MC = min LAC  ·  π = 0

Каждая выжившая фирма работает в минимуме долгосрочных средних издержек (оптимальный размер завода).

π = 0 — это экономическая прибыль = 0, не бухгалтерская. Фирма получает нормальную прибыль (= альтернативная стоимость капитала) — это не «убыток».

Exam #15 cheat sheet:
· Условия: много фирм, однородный продукт, свободный вход, price taker
· Спрос фирмы: горизонтальный при P* · P = MR = AR
· SR: produce where P = MC if P ≥ min AVC; else shutdown
· SR supply = MC above min AVC
· LR: P = MC = min LAC, economic profit = 0
· vs monopoly: P = MC (not MR = MC with P > MC)
