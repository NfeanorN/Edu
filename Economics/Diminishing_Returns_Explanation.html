Закон убывающей отдачи

Frank, гл. 8 · Figure 10.1

Есть одна кухня и один гриль (не меняются). Ты нанимаешь всё больше поваров. Сначала каждый новый повар много помогает. Потом — всё меньше. Вот это и есть закон убывающей отдачи.

One fixed kitchen, one grill. Hire more cooks — each new cook helps less and less. That's diminishing returns.

1. Главное — одной фразой

Больше workers → больше выпуска. Но если машины и площадь не растут, то каждый следующий worker добавляет всё меньше новых бургеров.

More workers still means more output — but each extra worker adds fewer and fewer burgers when space and equipment stay the same.

Важно: выпуск не обязательно падает. Он растёт, но всё медленнее. 81 бургер → 86 бургеров — рост есть, просто маленький (+5).

2. Пример: нанимаем поваров по одному

Гриль один. Смотрим, сколько бургеров в час и сколько добавил именно последний повар:

«Добавил последний» = новый минус старый. Например: 58 − 43 = +15

Last column = how many burgers the newest cook added. 58 − 43 = 15 from the 5th cook.

4 повара → 43 бургера. Наняли 5-го → стало 58

5-й повар добавил: 58 − 43 = 15 бургеров

7-й повар добавил: 81 − 72 = 9 — уже меньше

После 4-го повара каждый новый добавляет меньше: 15 → 14 → 9 → 5. Это и есть закон.

3. Что значит MP (marginal product)

Колонка «добавил последний» — это и есть MP (предельный продукт). Просто другое название для «прироста от последнего worker».

MP = marginal product = extra output from the last worker = Q now − Q before.

MP = новый выпуск − старый выпуск   (при +1 worker)

4. График — кривая «выпрямляется»

По оси X — число workers. По оси Y — всего бургеров (Q). Кривая идёт вверх, но после 4-го повара становится положе — рост замедляется.

Q растёт всегда ↑ · но кривая «ломается» — после 4 поваров рост замедляется

5. Почему так?

1 повар — один на всю кухню, медленно.
2–3 повара — один жарит, другой собирает бургер → быстрее.
4 повара — ещё ок, но уже тесно.
7–8 поваров — мешают друг другу, гриль один → каждый новый почти ничего не добавляет.

Specialization helps at first. Then fixed grill and space limit how much each extra cook can add.

6. Формула MC

MC = w / MP
w = зарплата одного worker (за час)
MP = сколько бургеров добавил последний worker

MC = wage / marginal product. Cost of one more unit = pay for the worker divided by how many units they add.

Зарплата повара w = $80 за час

4-й повар добавил MP = 16 бургеров

MC = 80 ÷ 16 = $5 за один бургер

8-й повар добавил MP = 5 бургеров

MC = 80 ÷ 5 = $16 за один бургер — в 3 раза дороже!

Логика: MP большой → на один бургер «уходит» мало труда → MC маленькая. MP маленький → тот же повар дорогой, а бургеров мало → MC большая.

High MP → low MC. Low MP → high MC. They move in opposite directions.

Ещё одна формула (для средних издержек): AVC = w / AP, где AP = Q ÷ L (бургеров на одного повара в среднем).

7. Почему MC — U-образная

Сначала MP растёт → MC падает. Потом MP падает → MC растёт. Минимум MC — там, где MP максимален (4-й повар).

MC = стоимость ещё одного бургера · минимум там, где повар добавляет больше всего (4-й)

8. Только краткий период (short run)

Закон работает, когда гриль/цех не меняется, а ты только нанимаешь людей.

Если построить вторую кухню — это уже долгий период → другая тема: Returns to Scale.

Short run = fixed capital, variable labour. Long run = can expand the kitchen too.

Шпаргалка

  • Гриль один, workers больше → Q растёт, но всё медленнее
  • «Добавил последний» = MP
  • После пика (4 повара) MP падает → diminishing returns
  • MC = w / MP · MP падает → MC растёт
  • Только short run
