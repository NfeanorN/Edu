Perfect Competition — Совершенная конкуренция

Источники: Lec 24-11-2025 & Lec 28-11-2025 (McGraw Hill, Perfect Competition) · Earl & Wakeley, Ch. 7 (Fig. 7.2–7.5) · Google Drawings — long-run supply · Frank Ch. 10 (доп.).

Lec 24: 4 условия, MR = MC. Lec 28: shutdown, SR/LR supply, producer surplus, entry/exit, LR equilibrium P = SMC = LMC = ATC = LAC.

1. Что это? Условия Ch. 10 · Exam #15

Совершенная конкуренция — рынок с тысячами одинаковых мелких фирм. Каждая фирма — «капля в океане»: не может влиять на цену → price taker (ценополучатель).

Perfect competition: many identical small firms, homogeneous product, free entry and exit, perfect information. Each firm takes the market price as given.

Условие (Lec 24)Смысл
Standardized productТовар одной фирмы — perfect substitute товара любой другой
Price takersФирма принимает рыночную цену как данную
Free entry and exitСвободный вход/выход; факторы мобильны в долгом периоде
Perfect informationФирмы и потребители полностью информированы
Frank (Ch. 10): если фирма поднимет цену хоть на один цент — все покупатели уйдут к соседу. Цена «навязывается сверху» рынком.

2. Рынок vs одна фирма Ch. 10

Рыночный спрос D — нисходящий. Спрос для одной фирмы — горизонтальная линия на уровне P*: фирма может продать любой объём q по цене P*, но ничего не продаст, если поднимет цену.

График 1. Слева — рынок (D, S, P*, Q*). Справа — одна фирма: горизонтальный спрос = P* (price taker).

  • D (зелёная) — рыночный спрос (нисходящая). Пересечение с S даёт P*, Q*.
  • S (синяя) — рыночное предложение (восходящая).
  • Красная точка — равновесие рынка (P*, Q*).
  • Горизонтальная линия фирмы — D = MR = AR = P*. Фирма может продать любой q по P*, но не выше.
  • q* — выбор объёма фирмой (определяется MC, см. гр. 2).

3. P = MR = AR и правило P = MC Ch. 10

Общее правило любой фирмы: MR = MC. При конкуренции каждая доп. единица продаётся по той же цене P → MR = P = AR.

MR = MC  →  при конкуренции P = MR  →  P = MC

π = TR − TC = P·Q − TC. Фирма выбирает только q (P задана рынком).

  • P > MC → ещё одна единица увеличивает прибыль → производить больше
  • P < MC → ещё одна единица снижает прибыль → производить меньше
  • P = MC → оптимум q*

Produce while P > MC; stop where P = MC. Same MB = MC logic as Frank Figure 1.1.

Frank (Figure 10.2): рыночная цена P = $20. Горизонталь P = 20 пересекает MC при q* = 260 → фирма производит 260 единиц. Если P вырастет до $25 — точка пересечения сдвигается вверх по MC → q* больше.

График 2. Правило Lec 24/28: MR = MC на восходящем участке MC. При P = MC фирма максимизирует прибыль.

  • P = MR — горизонтальная линия рыночной цены (price taker).
  • MC — предельные издержки. Пересечение с P = точка q*.
  • ATC — средние полные издержки. Если P > ATC → экономическая прибыль (зелёная область).
  • q* — где P = MC. Производить, пока MR > MC; остановиться при MR = MC.

4. Краткосрочный период (SR) Ch. 10

K фиксирован. Возможны три случая:

УсловиеРезультат
P > ATCЭкономическая прибыль π > 0
P = ATCBreak-even, π = 0
AVC < P < ATCУбыток, но лучше работать (покрываем VC + часть FC)
P < min AVCShutdown — закрыться, q = 0

Правило shutdown Ch. 10, p. 307

Работать, если P ≥ min AVC

Закрыться, если P < min AVC

В SR FC платятся в любом случае → вопрос: покрывает ли выручка хотя бы переменные издержки?

Frank — пекарня: FC = $1 000/мес, min AVC = $2/багет, min ATC = $4.
P = $3: 3 > AVC → работать. Каждый багет даёт $1 на FC. 500 багетов → убыток $500 (лучше, чем $1 000 при закрытии).
P = $1,50: 1,50 < AVC → закрыться. Убыток = FC = $1 000.

Краткосрочное предложение фирмы Fig. 10.4

Кривая предложения фирмы в SR = участок MC выше min AVC. Ниже min AVC фирма производит 0 → «скачок» от оси q к MC.

График 3. Earl Fig. 7.2: xz = SR supply (MC выше min AVC). Ниже min AVC — shutdown, q = 0.

  • MC — marginal cost.
  • AVC — average variable cost. Минимум AVC = порог shutdown.
  • Оранжевый участок MC — краткосрочное предложение фирмы (Lec 28: rising MC above min AVC).
  • Если P < min AVC — закрыться (убыток = FC). Если P ≥ min AVC — производить где P = MC.

Lec 28 — вход/выход: π > 0 → новые фирмы входят → S сдвигается вправо → P↓. Процесс до:

  1. P = минимум LAC
  2. Каждая фирма на оптимальном размере завода (SAC касается LAC)

LR равновесие (Lec 28, slide 27):

P* = SMC* = LMC = ATC* = LAC  ·  экономическая прибыль всех фирм = 0

Google Drawings — спрос вырос: SR vs LR

Числа с вашей схемы: изначально P = 5€, Q = 2000, фирма q = 20 (P = MC = min ATC). Спрос сдвигается D → D₁ → в кратком периоде P = 8€, фирма q = 22, ATC = 5,5€ → прибыль. Потом вход фирм → S вправо → P обратно к 5€.

График 4. Слева — одна фирма (MC, ATC). Справа — рынок (S, D, D₁). Показывает краткосрочную реакцию на рост спроса.

  • Левая панель — фирма:
    • P = 5€ — долгосрочное равновесие: q = 20, P = MC = min ATC, π = 0.
    • P = 8€ (пунктир) — краткосрочно после сдвига D₁: q = 22, MC = 8, ATC = 5,5€ → прибыль (P > ATC).
    • MC — фирма выбирает q где P = MC.
    • ATC — при q = 22 средние издержки 5,5€.
  • Правая панель — рынок:
    • D — исходный спрос. D ∩ S → P = 5€, Q = 2000.
    • D₁ — спрос вырос (сдвиг вправо).
    • S — предложение отрасли (в SR фиксировано число фирм).
    • Краткий период: D₁ ∩ S → P = 8€. При старой цене 5€ на D₁ спрос = 2500 > 2000 → дефицит → цена растёт.
    • Долгий период: π > 0 → вход фирм → S вправо → P снова → 5€, Q выше 2000 (LRS).

В конкуренции выпуск Qc где P = MC — allocative efficiency, суммарный излишек максимален. Монополия ограничивает Q → DWL. См. Monopoly, Market Power.

График 5. Конкурентное равновесие: P = MC, allocative efficiency, CS + PS без DWL.

c Pc=MC CS PS
  • D — спрос. MC — предложение в конкуренции (P = MC).
  • Qc, Pc — равновесие где P = MC. Зелёная зона = CS, синяя = PS (producer surplus, Lec 28).
  • Нет DWL — в отличие от монополии.
Exam #15 cheat sheet:
· Условия: много фирм, однородный продукт, свободный вход, price taker
· Спрос фирмы: горизонтальный при P* · P = MR = AR
· SR: produce where P = MC if P ≥ min AVC; else shutdown
· SR supply = MC above min AVC
· LR: P = MC = min LAC, economic profit = 0
· vs monopoly: P = MC (not MR = MC with P > MC)
