1. Что такое потребление (C)?

What is consumption at all? / Что такое потребление?

Макроэкономика (экзамен): C (consumption) — расходы домохозяйств на товары и услуги: еда, аренда, одежда, транспорт, услуги. Крупнейшая часть ВВП.

Y = C + I + G + NX   (закрытая: Y = C + I + G)

C = household spending · I = investment · G = government spending · NX = exports − imports

In macro, C is total household spending on final goods and services — a component of aggregate demand.

Не путать с микро (Frank): там потребитель выбирает корзину товаров при MU/P = MU/P и бюджетном ограничении — это индивидуальный выбор. Макро C(Y) — совокупные траты всех домохозяйств от дохода Y.

2. Функция потребления

Consumption function — что это и как записать?

C = c₀ + c₁Y Exam #11

c₀ — autonomous consumption (автономное потребление)

c₁ = MPC — marginal propensity to consume (0 < c₁ < 1)

MPS = 1 − MPC — marginal propensity to save

ПонятиеФормулаСмысл
MPCΔC / ΔY = c₁Доля дополнительного дохода на траты
MPSΔS / ΔYДоля доп. дохода на сбережения
Наклон C(Y)= MPCExam #30 — не −Px/Py!
Exam Prep: MPC = 0,8 → +€100 дохода → +€80 потребления, +€20 сбережений.

Функция потребления: начинается в c₀, наклон = MPC. Подробнее — Consumption Function.

3. Что с потреблением, если нет дохода (Y = 0)?

What happens to consumption if there is no income?
C = c₀ > 0 — потребление не обнуляется. Люди тратят на базовые нужды из сбережений, кредита, трансфертов (пенсия, пособия).
YC = 100 + 0,8YS = Y − CИнтерпретация
0100−100Dissaving — живут «в долг» / за счёт накоплений
5005000Break-even: C = Y, S = 0
1 000900+100Сберегают €100

Break-even income (где C = Y):   Y* = c₀ / (1 − c₁)

Пример: 100 / (1 − 0,8) = 500

At Y = 0, consumption equals autonomous c₀, not zero. Households dissave or borrow to cover basic spending.

4. Доходная эластичность спроса (YED)

Income elasticity of demand — формула и типы товаров

YED = (% change in Qd) / (% change in Income)

YED = (% ΔQ) / (% ΔY)

YEDТип товараПример
> 0Normal good (нормальный)Доход ↑ → покупаем больше
< 0Inferior good (низший)Доход ↑ → покупаем меньше (лапша быстрого приготовления)
> 1Luxury (роскошь)Спрос растёт быстрее дохода
0 < YED < 1Necessity (необходимость)Спрос растёт медленнее дохода (хлеб, коммуналка)
Доход +10%, спрос на рестораны +15% → YED = 15/10 = 1,5 (luxury). Доход +10%, спрос на хлеб +3% → YED = 0,3 (necessity).

YED tells how demand responds to income changes — separate from price elasticity (PED).

→ Elasticities of Demand (section 2)

5. ЦБ продаёт облигации — что происходит?

What happens if the central bank sells bonds?

Open market operation (OMO) — Exam Prep #25:

  1. ЦБ продаёт государственные облигации
  2. Банки / домохозяйства платят деньги ЦБ
  3. M ↓ — деньги изъяты из экономики
  4. Денежный рынок: предложение денег сдвигается влево
  5. i ↑ — ставка растёт
  6. I ↓ (кредит дороже) · C ↓ (выгоднее сберегать)
  7. AD ↓ → через мультипликатор Y ↓

Продажа облигаций = contractionary monetary policy. Обратное: покупка облигаций → M↑ → i↓ → Y↑.

CB sells bonds → M↓ → i↑ → I↓, C↓ → Y↓
CB buys bonds → M↑ → i↓ → I↑, C↑ → Y↑

→ Fiscal & Monetary Policy · Exam #19, #25

6. Что будет после рецессии?

What is going to happen after a recession?

Рецессия — Y ниже потенциального, высокая циклическая безработица, слабый спрос. После рецессии (восстановление):

ПеременнаяТипичное движениеПочему
Y (GDP)↑ к потенциальному уровнюСтимул спроса, мультипликатор
u (unemployment)↓Циклическая безработица снижается
C↑Больше дохода, больше уверенности
I↑Ниже i, лучшие ожидания
π (inflation)может ↑ (краткосрочно)Кривая Филлипса: u↓ → давление на цены

Закон Оукена (Okun): при восстановлении Y↑ → u↓ (обратная связь). Правило: 1 pp безработицы ≈ 2% output gap. → Okun & Phillips

Okun's Law: as Y recovers, unemployment falls. Rule of thumb: 1 pp u ≈ 2% output gap.

Политика восстановления (expansionary):

  • Фискальная: G↑, T↓ → IS вправо → Y↑
  • Денежная: M↑, i↓ → LM вправо → Y↑
Парадокс бережливости: если все сберегают больше (MPC↓) во время спада → AD↓ → Y падает ещё сильнее → сбережения могут не вырасти. См. Multiplier.

Recovery: GDP and consumption rise, unemployment falls. Governments often use expansionary fiscal and monetary policy to speed this up.

7. IS-LM: числовой пример (найти Y* и i*)

IS-LM — given data, find equilibrium Y and interest rate i

Алгоритм (Exam #26): всегда два шага — вывести IS, записать LM, решить систему.

Дано

C = 50 + 0.75Y · I = 200 − 20i · G = 50

M = 200 · L = 0.25Y − 5i

Шаг 1 — IS (рынок товаров: Y = C + I + G)

Шаг 2 — LM (денежный рынок: M = L)

LM:  200 = 0.25Y − 5i

Шаг 3 — подстановка

Проверка LM: 0,25 × 880 − 5 × 4 = 220 − 20 = 200 ✓

Если ЦБ продаёт облигации (M: 200 → 150)

Равновесие IS ∩ LM: Y* = 880, i* = 4. Полный разбор — IS-LM Model.

IS-LM cheat sheet:
1) IS из Y = C + I + G → выразить Y через i
2) LM из M = L(Y, i)
3) Подставить → i* → Y*
4) Всегда проверить подстановкой в LM
