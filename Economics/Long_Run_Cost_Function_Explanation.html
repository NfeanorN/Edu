График LTC с лекции

Frank, гл. 9 · long run

Долгий период = можно менять и пекарей, и печи. График показывает: сколько всего денег нужно, чтобы произвести Q пирогов.

Long run: both labour and capital are variable. The graph shows total cost (LTC) for each output level Q.

На других страницах: LAC или LRAC = LTC ÷ Q ($ за пирог) — средние издержки в long run. Это одно и то же.

Оси

Вправо (Q) — сколько пирогов произвели.

Вверх (LTC) — сколько всего потратили $. Чем выше точка — тем больше денег.

X-axis = output Q · Y-axis = total cost LTC ($). Higher on the graph = more money spent.

Что такое RTS

RTS = Returns to Scale = отдача от масштаба.

Один вопрос: удвоил всё (печи и пекарей) — пирогов стало в 2 раза больше, больше чем в 2 раза, или меньше?

Returns to scale (RTS): if you double all inputs, does output double, more than double, or less?

Было: 1 печь + 2 пекаря → 100 пирогов

Стало: 2 печи + 4 пекаря (всё ×2)

250 пирогов → increasing RTS (больше чем ×2) → зелёная линия
200 пирогов → constant RTS (ровно ×2) → чёрная прямая
150 пирогов → decreasing RTS (меньше чем ×2) → красная линия

250 pies = increasing RTS (green, below line) · 200 = constant (diagonal) · 150 = decreasing (red, above line).

RTS — про выпуск. График LTC — про деньги. Связь: если при росте выпуск «не успевает» за затратами → тратишь больше на каждый пирог → линия выше прямой.

RTS is about output when scaling up. The LTC graph is about money. If output grows slower than costs → line above the diagonal → costlier per unit.

≠ diminishing returns (там +1 повар при той же печи). → Diminishing Returns · подробнее → Returns to Scale

Три линии на графике

Все начинаются из нуля и сходятся в Q*. Каждая линия = свой тип RTS:

ЛинияRTSПо-русски
① Чёрная прямая constant Удвоил пироги → удвоились траты
② Зелёная, ниже increasing Тратишь меньше — пирог дешевле
③ Красная, выше decreasing Тратишь больше — пирог дороже

«Ниже прямой» = линия ближе к оси Q = меньше $, не «выше на экране».

Below the diagonal = lower total cost at the same Q = cheaper to produce.

Пример: Q = 200 пирогов

Проведи вертикаль вверх от Q=200

Попадёшь в три точки — три разные суммы:

Зелёная: $400 всего → 400÷200 = $2 за пирог
Чёрная: $500 всего → 500÷200 = $2.50 за пирог
Красная: $600 всего → 600÷200 = $3 за пирог

Зелёная ниже → дешевле. Красная выше → дороже. Всё.

Green below = cheaper per pie ($2) · black on diagonal = $2.50 · red above = $3.

RTS = что с выпуском, если удвоить всё
График = сколько $ при каждом Q
increasing → зелёная ниже · constant → прямая · decreasing → красная выше

Increasing RTS → green below · constant → diagonal · decreasing → red above.

Рисунки Frank — зачем они

Коротко: график с лекции = три линии LTC сразу, для сравнения. Рисунки Frank = подробнее, по одному случаю RTS, плюс LAC/LMC снизу. На экзамене достаточно понимать связь — не зубрить все номера рисунков.

Lecture graph = three LTC curves compared. Frank figures = one RTS case at a time, with LAC/LMC below. Same ideas, more detail.

РисунокЗачемСвязь с лекцией
9.15–9.16 Как фирма выбирает дешёвый mix L и K → отсюда LTC. U-образная LAC — минимум $/шт. Общий случай (не только constant/increasing/decreasing)
9.17 Идеальный случай: constant RTS. LTC — прямая, LAC = LMC — горизонталь. = ① чёрная прямая на лекции
9.18 / 9.19 Два крайних случая: decreasing (LTC круче) и increasing (LTC положе). = ③ красная и ② зелёная

Fig. 9.15–9.16 — откуда берётся LTC

Зачем: показать, что LTC — не из воздуха: фирма крутит L и K и ищет самый дешёвый способ. Снизу — LAC (U-образная): есть «лучший» размер фирмы.

Fig 9.15–16: how the firm picks the cheapest input mix → LTC. Bottom panel: U-shaped LAC = optimal scale.

Fig. 9.17 — constant RTS

Зачем: самый простой пример. Удвоил Q → удвоил $. $ за пирог не меняется. Это эталон «прямой» с лекции.

Simplest case: double output → double cost. LAC = LMC = flat line.

Fig. 9.18 / 9.19 — decreasing и increasing RTS

Зачем: два противоположных случая. 9.18 — растёшь, но $/шт растёт (плохо). 9.19 — растёшь, $/шт падает (economies of scale → может быть natural monopoly).

9.18: diseconomies — unit cost rises. 9.19: economies of scale — unit cost falls.

Итого — зачем все вместе:
1) Лекция — быстро: какая линия LTC при каком RTS
2) Frank 9.16 — реальная U-образная LAC (сначала дешевеет, потом дорожает)
3) Frank 9.17–9.19 — три «чистых» случая RTS, чтобы не путать формы кривых
