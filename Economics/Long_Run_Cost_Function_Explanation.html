Long Run Cost Function — Долгосрочная функция издержек

Long-run cost function (LRTC) — минимальные издержки при каждом выпуске Q, когда фирма может свободно менять все факторы (труд L и капитал K).

LRTC(Q) = minimum total cost at each output level when all inputs are variable.

1. Short run vs long run / Краткий vs долгий период

ComparisonShort runLong run
ФакторыInputsХотя бы один фиксирован (обычно K)At least one fixed (usually K)Все переменныеAll variable
ВопросQuestionСколько произвести при данном заводе?How much to produce with given plant?Какой mix (L, K) и какой размер завода?Which mix (L, K) and plant size?

In the long run there are no fixed inputs — the firm picks the cheapest way to produce each Q.

Diagonal = constant returns. Curve below = economies of scale. Curve above = diseconomies of scale.

  • LRTC ниже прямой → LAC ↓ (economies of scale)
  • LRTC выше прямой → LAC ↑ (diseconomies of scale)
  • LRTC на прямой → LAC постоянна

LRTC below the line → LAC falls (economies of scale). LRTC above → LAC rises (diseconomies). LRTC on the line → LAC constant.

При increasing RTS крупная фирма производит дешевле на единицу (специализация, опт). При decreasing RTS слишком большая фирма неэффективна (бюрократия, координация).

With increasing RTS, a larger firm has lower unit cost (specialization, bulk buying). With decreasing RTS, an oversized firm is inefficient (bureaucracy, coordination).

3. Формулы / Formulas

LRTC(Q) = min (w·L + r·K)   при   Q = f(L, K)
w — зарплата · r — цена капитала · выбираем самую дешёвую пару (L, K)

LRTC(Q) = minimum of w·L + r·K subject to Q = f(L, K). Choose the cheapest (L, K) pair.

LAC = LRTC / Q
LAC — long-run average cost (средние издержки в долгом периоде)

LAC = LRTC / Q — long-run average cost per unit of output.

Returns to scale (удвоили все факторы, k = 2) / Returns to scale (double all inputs)

ТипTypeУсловиеConditionLRTC на графикеLRTC on graph

Increasing RTS: doubling inputs more than doubles output (below line). Constant: exactly doubles. Decreasing: less than doubles (above line).

4. Пример — пекарня (Frank) / Example — bakery (Frank)

1 печь + 2 пекаря = 100 пирогов/день

Удваиваем всё: 2 печи + 4 пекаря

250 пирогов → increasing RTS (ниже прямой, LAC падает)

200 пирогов → constant RTS (на прямой)

150 пирогов → decreasing RTS (выше прямой, LAC растёт)

1 oven + 2 bakers = 100 pies/day. Double all: 2 ovens + 4 bakers → 250 pies = increasing RTS; 200 = constant; 150 = decreasing.

5. От формы LAC — к структуре отрасли / From LAC shape to industry structure

  • LAC падает → крупная фирма дешевле → монополия (электричество, вода)
  • LAC растёт → мелкие фирмы лучше → много салонов, ресторанов
  • LAC плоская → размер не важен

Falling LAC → big firm is cheaper → monopoly (utilities, water). Rising LAC → small firms better → many salons, restaurants. Flat LAC → size doesn't matter.

LRTC = min cost при всех переменных факторах · Прямая 45° = constant RTS
Ниже прямой = increasing RTS = LAC↓ · Выше = decreasing RTS = LAC↑
LAC = LRTC / Q · Frank Ch. 9

LRTC = min cost with all inputs variable · 45° line = constant RTS · Below = increasing RTS = LAC down · Above = decreasing RTS = LAC up · LAC = LRTC / Q · Frank Ch. 9.

Долгосрочная функция издержек показывает, сколько стоит произвести Q при оптимальном выборе L и K. График с прямой и двумя кривыми — это отдача от масштаба: ниже прямой = дешевле расти, выше = дороже расти.

The long-run cost function shows the cost of producing Q with the optimal choice of L and K. The graph with a line and two curves shows returns to scale: below the line = cheaper to grow, above = costlier to grow.
