Price Discrimination — Ценовая дискриминация

Связано с Robert H. Frank, Microeconomics and Behavior, 7th ed., Chapter 11 (монополия, MR < P). Числовой пример — тот же, что в Monopoly: P = 10 − Q, MC = 2. Степени дискриминации — Exam Prep Topics 33–34.

1. Что это и зачем монополисту? / What & why

Ценовая дискриминация (price discrimination) — продавать один и тот же товар разным покупателям по разным ценам, ближе к их готовности платить (WTP / reservation price).

Price discrimination = charging different prices for the same good based on willingness to pay, not on different costs.

Проблема «одной цены»

Монополист с одной ценой P* (Frank, Ch. 11):

  • Оптимум: MR = MC → при P = 10 − Q, MC = 2 получаем Q* = 4, P* = 6, π = 16.
  • Часть покупателей с высоким WTP платит только 6 $, хотя готовы больше → consumer surplus (CS) остаётся у них.
  • Часть с низким WTP (между 2 и 6 $) не покупает → объём меньше, чем при конкуренции (Qc = 8).
  • Между Q* и Qc — deadweight loss (DWL): единицы, где WTP > MC, не производятся.

With a single price, the monopolist leaves consumer surplus on the table and restricts Q below the competitive level — deadweight loss.

Frank (Ch. 11): без дискриминации Q* = 4, P* = 6 $. С perfect discrimination монополист мог бы продать до Q = 8 (где P = MC = 2), взимая с каждой единицы её WTP — π растёт, DWL исчезает.

3. Первая степень — perfect price discrimination Exam #34

Главная идея

При обычной монополии, чтобы продать +1 единицу, нужно снизить P на всех → MR < P. При perfect discrimination каждая единица продаётся по своей цене (WTP) — снижение цены на старых единицах не нужно → MR = D.

No need to cut price on all previous units → marginal revenue equals demand.

Perfect discrimination: MR = D

Оптимум: MR = MC → D = MC → последняя единица по цене P = MC

Объём = конкурентный (нет DWL), но весь CS забирает продавец

Числа: Frank Ch. 11 — P = 10 − Q, MC = 2

  1. Одна цена: MR = 10 − 2Q = MC = 2 → Q* = 4, P* = 6, π = (6−2)×4 = 16.
  2. Perfect discr.: D = MC → 10 − Q = 2 → Q** = 8 (как при конкуренции).
  3. Каждая из 8 ед. по своей цене: 1-я по 9 $, 2-я по 8 $, … 8-я по 2 $.
  4. TR = площадь под D до Q = 8 = (10+2)/2 × 8 = 48; TC = 2×8 = 16 → π = 32 (вдвое больше!).

Оранжевый — π при одной цене (Q*=4, P*=6). Фиолетовый — π при perfect discrimination (Q**=8, каждая ед. по WTP). Красный треугольник — DWL при одной цене (исчезает при perfect discr.).

Perfect discrimination: MR = D → оптимум там, где D пересекает MC → Q** = 8, последняя цена = 2 $. Нет DWL.

4. Вторая степень / Second-degree

Продавец не знает WTP каждого клиента, но предлагает меню тарифов: чем больше покупаешь — тем ниже цена за единицу (или разные «версии» товара).

The firm offers quantity discounts or product versions so buyers self-select — high-WTP types buy more or premium bundles.

  • Оптовая скидка: 1 шт. — 6 $, пакет 5 шт. — 25 $ (5 $/шт.) — «тяжёлые» покупатели берут пакет.
  • Версии: Basic / Pro / Enterprise — разная цена за разный набор функций.

Логика: заставить покупателей самим раскрыть свой тип (self-selection), не спрашивая напрямую «сколько готовы платить?».

5. Третья степень / Third-degree

Рынок делится на отдельные сегменты с разной эластичностью спроса. Правило:

Выше цена → менее эластичный сегмент (inelastic demand)

Ниже цена → более эластичный сегмент (elastic demand)

Связь с наценкой: (P − MC) / P = 1 / |ε| (Lerner index) — при малом |ε| markup большой

Авиабилеты: business (inelastic, срочно) — P высокая; студенты / leisure (elastic) — P ниже. Оба сегмента платят ближе к своему WTP, чем при одной цене.

3-я степень: два изолированных рынка. На каждом — свой MR = MC → разные P*. Эластичный сегмент получает скидку.

Условие успеха: сегменты не могут перепродавать друг другу (иначе все купят по низкой цене B).

Зачем: при одной цене P* часть WTP «теряется» — дискриминация захватывает CS → ↑ TR и π.
