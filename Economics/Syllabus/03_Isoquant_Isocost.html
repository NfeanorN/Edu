Topic 3: Isoquant & Isocost — Produce More with Less Unit Cost

Source: Frank, Ch. 9 — Figures 9.10, 9.13

Isoquant: all (L, K) bundles that produce the same output Q. Higher curve = more output.

Isocost: all bundles that cost the same: C = wL + rK. Slope = −w/r.

Minimum cost for a given Q = tangency (touch point) of isoquant and the lowest possible isocost line.

With increasing returns to scale (Ch. 9), scaling up both L and K can raise Q faster than cost — so unit cost (AC) falls. That is how you "produce more with less cost per unit."
Optimum: MRTS = MPL/MPK = w/r

Green = isoquants (Q₁, Q₂). Orange = isocosts. Purple dots = cost-minimizing tangency points.

Properties (Ch. 9)

  • Isoquant: convex to origin, higher = more Q, slope = MRTS = MPL/MPK.
  • Isocost: straight line, slope −w/r; parallel lines = different budgets.
  • Optimum: lowest isocost tangent to target isoquant.

Exam phrase

«With increasing RTS, scaling up lowers unit cost because output grows faster than total cost.»

🇷🇺 По-русски

Изокванта — комбинации L и K с одинаковым Q. Изокоста C = wL + rK, наклон −w/r. Минимум издержек = касание. При возрастающей отдаче от масштаба увеличение масштаба снижает средние издержки — «больше продукции за меньшую цену на единицу».
