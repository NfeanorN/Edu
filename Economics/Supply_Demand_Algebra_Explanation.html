Algebra of Supply & Demand

Linear D and S · solve for P* and Q* · exam algebra

Если спрос и предложение заданы линейными уравнениями, равновесие: приравнять P из D и S → найти Q*, затем P*.

With linear demand and supply equations, set them equal to find Q*, then plug back for P*.

Demand: P = a − bQ  |  Supply: P = c + dQ  |  Equilibrium: a − bQ = c + dQ
Q* = (a − c) / (b + d) · then P* from either equation

General: Q* = (a − c)/(b + d). Substitute into demand or supply for P*.

Exam example / Пример с экзамена

D: P = 10 − Q   ·   S: P = 2 + 3Q

Demand P = 10 − Q. Supply P = 2 + 3Q.

Step 1: Set D = S  →  10 − Q = 2 + 3Q

Step 2: 10 − 2 = 3Q + Q  →  8 = 4Q

Step 3: Q* = 8 / 4 = 2

Step 4: P* = 10 − 2 = 8  (or P* = 2 + 3×2 = 8)

Equilibrium: Q* = 2, P* = 8

10 − Q = 2 + 3Q → Q* = 2. P* = 10 − 2 = 8. Check: 2 + 3(2) = 8 ✓

D: P=10−Q · S: P=2+3Q · пересечение (2, 8)Equilibrium at Q*=2, P*=8.

Second form: Q as function of P

Sometimes D: Q = 10 − P   and   S: Q = 2 + 0.5P

Set Q equal: 10 − P = 2 + 0.5P → 8 = 1.5P → P* = 16/3 ≈ 5.33

Same logic — set quantities equal at equilibrium

You may get Q = f(P) instead of P = f(Q). Set Q_D = Q_S and solve for P*.

Exam steps: (1) write D and S · (2) set equal · (3) solve Q* · (4) plug for P* · (5) check in both equations

Exam: write equations, set equal, solve Q*, find P*, verify.

Алгебра S&D: приравняй P (или Q) из D и S → Q*, P*. Пример: P=10−Q и P=2+3Q → Q*=2, P*=8.

Set demand equal to supply, solve for Q* and P*. Example: P=10−Q and P=2+3Q gives Q*=2, P*=8.
