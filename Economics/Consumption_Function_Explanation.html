Consumption Function — Функция потребления

Источник: Exam Prep Guide — Topics #11 (MPC, MPS), #30 (наклон C(Y) = MPC). Не в Frank (микро: MU/P, бюджетное ограничение — см. Rational Choice). Макро: потребление зависит от дохода Y.

1. Что это? Exam #11

Функция потребления показывает, сколько домохозяйства тратят (C) при данном совокупном доходе (Y). В краткосрочной Keynesian модели:

C = c₀ + c₁Y

c₀ = autonomous consumption (автономное потребление) — траты при Y = 0 (минимум на еду, жильё и т.д.)

c₁ = marginal propensity to consume MPC — доля дополнительного дохода, которую тратят (0 < c₁ < 1)

Consumption rises with income. Autonomous part c₀ is spending independent of current Y; each extra euro of income adds MPC × € to consumption.

2. MPC и MPS Exam #11

ПонятиеФормулаСмысл
MPC (marginal propensity to consume)MPC = ΔC / ΔY = c₁Сколько из ещё одного € дохода уйдёт на потребление
MPS (marginal propensity to save)MPS = ΔS / ΔYСколько из доп. € дохода уйдёт на сбережения

MPC + MPS = 1

Каждый дополнительный € дохода либо тратится, либо сберегается.

Exam Prep: MPC = 0,8 → из каждых +€100 дохода люди тратят €80, сберегают €20 (MPS = 0,2).

4. График C(Y) Exam #30

Ось X — доход Y, ось Y — потребление C. Линия C = c₀ + c₁Y начинается в точке (0, c₀) и идёт вверх с наклоном MPC = c₁.

Slope of the consumption function = MPC. Not the same as the budget-line slope in micro (−Px/Py) — Exam Topic #30.

C(Y): intercept = c₀; наклон = MPC. Пересечение с 45° (C=Y) — доход, при котором S=0. Ниже Y* люди «тратят больше дохода» (dissaving).

На экзамене часто подставляют MPC туда, где нужен −Px/Py, или наоборот. Проверяй оси: C vs Y — это макро; X vs Y (два товара) — микро.

6. Сдвиги функции потребления

Изменение c₁ (MPC) → поворот линии (круче/площе). Изменение c₀ → параллельный сдвиг вверх/вниз.

Что изменилосьЭффект на графикеПример
c₀ ↑C сдвигается вверх при любом YНалоговые выплаты, оптимизм, рост богатства
c₀ ↓C сдвигается внизСтрах рецессии, рост долгов
c₁ (MPC) ↓Линия становится площеЛюди сберегают больше из доп. дохода
c₁ (MPC) ↑Линия кручеБольше тратят из каждого € дохода

Рост c₀ или c₁ → больше C при том же Y → выше совокупный спрос Z → через мультипликатор растёт Y. См. Goods Market & Multiplier.

7. C в модели равновесия

В закрытой экономике планируемый спрос:

Z = C + I + G   (X − M в открытой)

Подставляем C = c₀ + c₁Y:

Z = c₀ + c₁Y + I + G

Равновесие: Y = Z → Y = c₀ + c₁Y + I + G → решение даёт Y*.

Линия AE = Z(Y) параллельна C(Y), но выше на I + G (если I, G не зависят от Y). Наклон AE = MPC → определяет мультипликатор = 1/(1−MPC).

Exam Prep (#11, #28): MPC=0,8 → multiplier=5. ΔG=€10 млрд → ΔY=€50 млрд. Round 1: +10 G; Round 2: +8 C; Round 3: +6,4 C… Сумма = 10×(1+0,8+0,64+…) = 10/0,2 = 50.

8. Парадокс бережливости (кратко)

Если все хотят сберегать больше → MPC падает → C при каждом Y ниже → Z падает → через мультипликатор Y падает. В итоге сбережения могут не вырасти (падение дохода съедает желаемые сбережения). Подробнее — Paradox of thrift.

9. Связь с другими темами

  • Микро (Frank): потребитель выбирает товары при MU/P — не то же самое, что C(Y). Rational Choice
  • Межвременной выбор: C зависит также от Ye, богатства, r — Intertemporal Budget (Exam #8)
  • Мультипликатор: Goods Market & Multiplier · Exam #28
  • IS-LM: кривая IS строится из Z(Y) — IS-LM
C = c₀ + c₁Y · MPC = c₁ = ΔC/ΔY · MPS = 1 − MPC · MPC + MPS = 1
Наклон C(Y) = MPC (не −Px/Py!) · Break-even: C=Y → Y* = c₀/(1−c₁)
Multiplier = 1/(1−MPC) = 1/MPS · ΔY = multiplier × Δ(c₀, G, I…)

🇷🇺 По-русски

Функция потребления C=c₀+c₁Y (макро). c₀ — автономное потребление при Y=0. MPC=c₁ — наклон. MPS=1−MPC. Связь с мультипликатором 1/(1−MPC).
