Consumption Function — Функция потребления

Consumption (C) — траты домохозяйств на товары и услуги. Зависит от располагаемого дохода YD (доход после налогов).

Consumption depends mainly on disposable income YD — income after taxes. When disposable income rises, consumption rises too.

YD = Y − T
Y — income (доход)  |  T — taxes (налоги)  |  YD — disposable income (располагаемый доход)
C = c₀ + c₁ · YD
c₀ — autonomous consumption: траты даже при Y = 0 (еда, жильё)
c₁ — MPC (marginal propensity to consume): доля дополнительного дохода на потребление
0 < c₁ < 1 — часть доп. дохода тратят, часть сберегают

Behavioral equation: shows how consumers change spending when income changes. Slope = MPC = c₁.

  • YD ↑ → C ↑
  • Налоги T ↑ → YD ↓ → C ↓
  • MPC + MPS = 1 (каждый доп. € либо тратится, либо сберегается)
Больше людей работают и получают доход → больше трат → выше C. Налоги «съедают» доход → меньше YD → меньше C.

positive slope — линия идёт вверх

Intercept = c₀ на оси C. Наклон = MPC. На экзамене не путать с бюджетной линией микро (−Px/Py).

Income Y = $100, Taxes T = $10 → YD = 100 − 10 = 90

c₀ = $20, c₁ = 0,8 (тратят 80% доп. дохода)

C = c₀ + c₁ · YD = 20 + 0,8 × 90 = 20 + 72

C = $92

Example: Y=100, T=10 → Y_D=90; c₀=20, MPC=0.8 → C = 20 + 72 = 92.
