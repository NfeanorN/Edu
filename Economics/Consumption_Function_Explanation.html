Consumption Function — Функция потребления

Macro course (Keynes / Blanchard) · не Frank Ch. 3 (там consumption = один потребитель, микро)

FAQ — Questions & Answers / Частые вопросы

Q1. What is consumption at all? / Что такое consumption вообще?

A: C — все траты домохозяйств на товары и услуги (еда, аренда, телефон…). Это буква C в GDP = C + I + G + (X − IM). Обычно самая большая часть ВВП. Не путать с I (фирмы) и с микро Frank (один потребитель, food + shelter).

A: Consumption (C) is total household spending on goods and services — the C in GDP. Usually the largest GDP component. Not investment (firms) and not Frank micro (one consumer's budget).

Q2. What is gonna happen after recession? / Что будет после рецессии?

A: В рецессии: GDP и доход Y ↓ → YD ↓ → C ↓ (вниз по линии C). Меньше трат → меньше спрос Z → Y падает ещё (мультипликатор). После рецессии (recovery): Y ↑ → YD ↑ → C ↑ → Z ↑ → Y ↑. Та же линия C(Y), но точка снова выше.

A: In a recession: income falls → consumption falls along the C line → demand falls → output falls further. After recession (recovery): income rises → consumption rises → demand and output recover. Same consumption line — you move down in recession, back up in recovery.

Q3. What happens to consumption if there is no income? / Что с C, если дохода нет?

A: При YD = 0: C = c₀ (autonomous consumption). Люди всё равно тратят на еду и жильё — за счёт сбережений, кредита или пособий. На графике линия начинается на оси C в точке c₀, не в нуле. Долго без дохода нельзя — сбережения кончатся.

A: If disposable income is zero: C = c₀ only. People still spend on basics, financed by past savings, borrowing, or transfers. On the graph the line starts at c₀ on the C-axis. Not sustainable forever — wealth runs out.

Consumption (C) в макро — это все траты домохозяйств на товары и услуги за период (еда, аренда, телефон, поездки…). Это буква C в формуле ВВП.

In macroeconomics, consumption (C) is total household spending on goods and services — the C in GDP = C + I + G + (X − IM). It is usually the largest part of GDP.

Зачем функция C(Y)? Кейнс: люди тратят в основном от текущего дохода. Если знаем Y (и налоги T), можем предсказать C — а C — главная часть спроса Z = C + I + G.

Keynes: spending depends mainly on current income. The consumption function lets us predict C from income — and C is the biggest part of aggregate demand Z.

Q2 — What happens after a recession? / Что после рецессии?

Recession — выпуск и доход падают (GDP ↓). Люди теряют работу → Y ↓ → YD ↓ → C ↓ (движение вниз по линии потребления).

In a recession, output and income fall. Unemployment rises → income falls → disposable income falls → consumption falls — a move down along the consumption function.

  • В рецессии: Y ↓ → YD ↓ → C ↓ → Z ↓ → Y ↓ ещё (мультипликатор)
  • После / recovery: Y ↑ → YD ↑ → C ↑ → Z ↑ → Y ↑ (экономика отскакивает)
  • Меньше дохода → меньше трат → меньше спрос → меньше производство — порочный круг вниз

Recession chain: lower Y → lower C → lower demand Z → lower Y again (multiplier). Recovery reverses the chain: higher income → higher consumption → higher output.

Было: Y = 100, T = 10, c₀ = 20, c₁ = 0,8 → YD = 90 → C = 92

Recession: Y падает до 70 → YD = 60

C = 20 + 0,8 × 60 = 20 + 48 = 68 (было 92 — траты упали на $24)

Recovery: Y снова 100 → C снова 92

Рецессия = точка ниже на той же линии C(Y). Восстановление = обратно вверх по линии.

Recession: Y falls from 100 to 70 → C falls from 92 to 68. Recovery: when Y returns to 100, C returns to 92. Same line — different points.

Q3 — What if there is no income? / Если дохода нет (Y = 0)?

Даже при YD = 0 люди всё равно что-то тратят — это c₀ (autonomous consumption): еда, жильё, базовые нужды.

Even at zero disposable income, people still spend something — that is c₀ (autonomous consumption): food, rent, basic needs.

YD = 0  →  C = c₀ + c₁ · 0 = c₀
c₀ > 0 — линия потребления не начинается в нуле, а выше оси YD

If disposable income is zero, C equals c₀ only. The consumption line intercepts the C-axis at c₀, not at the origin.

  • Откуда деньги при Y = 0? → сбережения прошлых лет (wealth)
  • или → кредит / займы
  • или → гос. трансферы (пособия) — в модели часто внутри c₀ или в G/T

With no income, people finance c₀ from past savings, borrowing, or government transfers. Long-run Y = 0 is not sustainable — wealth runs out.

c₀ = $20, c₁ = 0,8

Потерял работу: Y = 0, T = 0 → YD = 0

C = 20 + 0,8 × 0 = $20 (живёт за счёт сбережений)

Нашёл работу: Y = 100, T = 10 → YD = 90

C = 20 + 0,8 × 90 = $92 — потребление выросло с доходом

Example: at Y_D = 0, C = c₀ = $20 (drawing on savings). When income returns to 90, C rises to $92.

Recession: Y↓ → C↓ (along C line) · Recovery: Y↑ → C↑ · c₀ = траты при Y=0 (savings/credit) · C = biggest part of Z

Recession lowers C via lower income. Recovery raises C. c₀ = spending at zero income. C is the largest part of aggregate demand.

Disposable income / Располагаемый доход

YD = Y − T
Y — income (доход)  |  T — taxes (налоги)  |  YD — disposable income

Disposable income = income minus taxes.

Consumption function / Поведенческое уравнение

C = C(YD)   →   C = c₀ + c₁ · YD
Поведенческое уравнение — показывает, как потребители меняют траты при изменении дохода

It's a behavioral equation because it shows how consumers change their spending when income changes.

СимволSymbolНазваниеNameСмыслMeaning

c₁MPCКакую долю дополнительного дохода люди тратятShare of extra income that people spend

c₀ = autonomous consumption (baseline spending). c₁ = MPC = marginal propensity to consume (slope of the consumption line).

0 < c₁ < 1 — люди тратят часть доп. дохода и сберегают остальное.

People spend some of their extra income and save the rest. 0 < c₁ < 1.

График C = c₀ + c₁YD / Graph of C = c₀ + c₁YD

  • Налоги T ↑ → YD ↓ → C ↓

Higher income → higher consumption. Higher taxes → lower disposable income → lower consumption.

Пример из конспекта / Example from notes

Income Y = $100 · Taxes T = $10

YD = 100 − 10 = 90

c₀ = $20 (траты даже без дохода)

c₁ = 0,8 (тратят 80% доп. дохода)

C = c₀ + c₁ · YD = 20 + 0,8 × 90 = 20 + 72

C = $92

Y = $100, T = $10 → YD = 90 · c₀ = $20 · c₁ = 0.8 · C = 20 + 0.8 × 90 = 20 + 72 = $92.
