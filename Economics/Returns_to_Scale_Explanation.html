RTS — отдача от масштаба

Frank, гл. 9 · конспект

RTS — удвоил всё (печи + людей) — выпуск вырос в 2 раза, больше чем в 2, или меньше?

Returns to scale (RTS): double all inputs — does output double, more than double, or less?

ТипУдвоил всё → выпуск
Increasingбольше чем ×2 (например ×2.5)
Constantровно ×2
Decreasingменьше чем ×2 (например ×1.5)

Increasing: output > ×2 · Constant: output = ×2 · Decreasing: output < ×2.

≠ diminishing returns (+1 повар, печь та же). → Diminishing Returns

Not the same as diminishing returns (short run: +1 worker, fixed oven).

Economies of scale — экономия от масштаба

Простыми словами: чем больше производишь — тем дешевле один товар (average cost падает).

Economies of scale: the more you produce, the lower the average cost per unit.

Q = 1 000 → $12 за штуку (точка S)

Q = 2 000 → $8 за штуку (точка M)

Q = 5 000 → $4 за штуку (точка L)

Больше выпуск → ниже cost per unit

More output → lower cost per unit (S $12 → M $8 → L $4).

Average cost падает при росте Q — economies of scaleAverage cost falls as output grows.

График LRAC (U-образная)

LRAC = LAC = одно и то же. Long-Run Average Cost = долгосрочные средние издержки = LTC ÷ Q ($ за один пирог).

LRAC and LAC are the same: long-run average cost = LTC ÷ Q = cost per unit of output.

Ось Y = cost per unit ($ за штуку). Ось X = output (Q).

Y-axis = cost per unit · X-axis = output Q · U-shaped long-run average cost (LRAC).

Слева дешевеет · посередине flat · справа дорожаетLeft: AC falls · middle: flat · right: AC rises.

УчастокRTSЧто происходит
Слева ↓increasingРастёшь — один товар дешевле
Дно —constantЦена за штуку не меняется
Справа ↑decreasingСлишком большая фирма — дороже

Left = increasing RTS (economies of scale) · flat bottom = constant RTS · right = decreasing RTS (diseconomies of scale).

Примеры из конспекта ($200 вложил)

RTSВыпуск$ за штуку
Increasing1000 шт200÷1000 = $0.20
Constant200 шт200÷200 = $1.00
Decreasing120 шт200÷120 = $1.60

Одинаковые $200 — но чем больше выпуск при increasing RTS, тем дешевле каждая штука.

Same $200 invested — with increasing RTS you get more units, so cost per unit is lowest ($0.20 vs $1.00 vs $1.60).
