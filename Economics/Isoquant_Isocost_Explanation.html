Isoquant & Isocost

Frank, гл. 9 · пекарня · long run

Ты владелец пекарни. Нужно 100 пирогов в день. Можно нанять пекарей (L) или поставить печи (K). Вопрос: какой mix дешевле всего?

You run a bakery. Need 100 pies/day. Hire bakers (L) or buy ovens (K). What's the cheapest mix?

1. Главное — одной фразой

Iso-cost = «iso» (равный) + cost — все варианты за одни и те же деньги.

Iso-quant = «iso» + quantity — все варианты с одним и тем же выпуском.

Фирма ищет касание: нужный выпуск + минимум денег.

Isocost = same money. Isoquant = same output. Optimum = where they touch.

Точно как у потребителя (Ch. 3):
Потребитель: budget line + IC → точка F
Фирма: isocost + isoquant → точка F
Только «товары» = пекари и печи.

2. Isocost — «$200 и всё»

У тебя $200 в неделю. Цены:

  • 1 пекарь = w = $50
  • 1 печь = r = $100
C = wL + rK  →  50L + 100K = 200

Вариант 1: 4 пекаря, 0 печей → 4×50 = $200 ✓

Вариант 2: 0 пекарей, 2 печи → 2×100 = $200 ✓

Вариант 3: 2 пекаря + 1 печь → 100+100 = $200 ✓

Все на одной красной линии — isocost

Four bakers, or two ovens, or two bakers + one oven — all cost exactly $200.

Красная линия = все комбинации ровно за $200

Наклон = −w/r = −50/100 = −½ (пекарь в 2 раза дешевле печи).

Slope = −w/r. A baker costs half as much as an oven.

3. Isoquant — «100 пирогов любым способом»

Нужно Q = 100 пирогов. Можно по-разному:

Много пекарей, мало печей: 10 пекарей + 2 печи → 100 пирогов
Мало пекарей, много печей: 3 пекаря + 5 печей → 100 пирогов

Разный набор — один выпуск → обе точки на зелёной кривой.

10 bakers + 2 ovens, or 3 bakers + 5 ovens — same 100 pies, same isoquant.

  • Выше зелёная → больше пирогов (200 > 100 > 50)
  • Кривые не пересекаются

Зелёная = isoquant · выше = больше выпуск

4. Оптимум F — касание

Задача: 100 пирогов за минимум $.

Смотрим зелёную Q=100

Ищем самую низкую красную линию, которая до неё дотягивается

Точка касания = F

Там дешевле всего сделать 100 пирогов

Find the lowest isocost line that still touches the Q=100 isoquant. Tangency point F = minimum cost.

F = касание · 100 пирогов за минимум денег

Не путать:
· Isocost = про деньги (красная, прямая)
· Isoquant = про выпуск (зелёная, кривая)
· F = ответ на экзамен

5. Long run — зачем это всё

В short run печь одна — меняешь только пекарей.

В long run можно и печи добавить — вот тогда isoquant + isocost.

Short run: fixed oven. Long run: choose both bakers and ovens.

6. Проверь себя

C=$200, w=$40, r=$80. Макс. пекарей?

200÷40 = 5

2 пекаря + 1 печь, w=50, r=100. Сколько $?

100+100 = $200

Isoquant выше = больше или меньше Q?

Больше

Шпаргалка

  • Isocost — одни $ · C = wL + rK · красная линия
  • Isoquant — один Q · зелёная кривая · выше = больше
  • F = касание = дешевле всего
