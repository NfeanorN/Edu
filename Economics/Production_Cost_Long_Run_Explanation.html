Production & Cost in the Long Run

Frank, Microeconomics and Behavior, 7th ed. · гл. 9 «Production and Cost in the Long Run» (стр. 278–286)

В long run фирма может менять всё: и труд (L), и капитал (K). Главный вопрос главы 9: как произвести Q при минимальных затратах?

In the long run all inputs are variable. The firm's main question: which mix of L and K produces output Q at the lowest cost?

1. Short run vs long run

SR: at least one input fixed. LR: all inputs variable — no fixed costs in the economic sense.

«Long run» — не календарь, а можно ли сейчас изменить размер завода? → Short / Medium / Long run

2. Два инструмента: isoquant + isocost

IsoquantIsocost
Что равноОдин и тот же QОдна и та же сумма C
ФормаКривая (выпуклая)Прямая
Аналог у потребителяIndifference curveBudget line

Isoquant = equal output. Isocost = equal cost. Same logic as consumer choice, but inputs are labour and capital.

C = w · L + r · K  ·  наклон isocost = −w/r

Isocost slope = −w/r. Higher wage w → steeper isocost.

Подробно с пекарней $200 и точкой F → Isoquant & Isocost

3. Оптимум — точка касания (Fig. 9.10)

Нужен заданный Q → остаёмся на isoquant → ищем самую дешёвую isocost (касание).

Stay on the required isoquant; touch the lowest possible isocost line.

MPL / MPK = w / r  или  MPL / w = MPK / r

At the optimum: output per dollar on labour = output per dollar on capital.

Зарплата w выросла (профсоюз)

w/r ↑ → isocost круче → точка касания влево-вверх

Фирма берёт больше K, меньше L — заменяет подорожавший труд

When w rises, substitute away from labour toward capital (robots, ovens).

4. От оптимума к LTC и LAC

Для каждого Q фирма находит дешёвый (L*, K*) → получаем LRTC (long-run total cost).

For each output level, find the cost-minimizing input mix → plot LRTC.

LAC = LRAC = LRTC / Q  — средние издержки в long run ($ за единицу)

LAC (LRAC) = long-run average cost = LRTC ÷ Q.

Три формы LRTC при разном RTS → график LTC (три линии)

RTSLRTCLAC
IncreasingНиже прямой (зелёная)Падает ↓
ConstantПрямая из (0,0)Плоская —
DecreasingВыше прямой (красная)Растёт ↑

Increasing RTS → economies of scale → falling LAC. Decreasing RTS → diseconomies → rising LAC.

→ Returns to Scale & LRAC (U-shape)

5. LAC — огибающая SAC (Fig. 9.13)

В SR у каждого размера завода своя кривая SAC (SR ATC). В LR фирма выбирает любой размер.

LAC — кривая минимально возможных средних издержек при идеально выбранном заводе для каждого Q.

LAC is the envelope of all SAC curves from below. Each SAC touches LAC at exactly one point — where that plant size is optimal for that Q.

Fig. 9.13: LAC касается каждой SAC в одной точке — оптимальный размер завода для данного QLAC touches each SAC at one point — optimal plant size for that Q.

  • Слева от касания: завод слишком мал → LAC < SAC → расширяйся
  • Справа: завод слишком велик → сокращайся
  • MES (minimum efficient scale) — Q, где LAC минимальна

MES = smallest output at which LAC is minimized. Below MES → still gaining scale economies.

6. LRMC и LAC

LRMC = ΔLRTC / ΔQ — наклон LRTC; издержки на +1 единицу, когда можно менять все факторы.

LRMC = slope of LRTC. Same logic as MC and ATC in the short run (Fig. 9.4).

Если…Тогда LAC…
LRMC < LACПадает (economies of scale)
LRMC > LACРастёт (diseconomies)
LRMC = LACМинимум LAC (MES)

LRMC crosses LAC at LAC's minimum — exactly like MC crosses ATC at ATC's minimum.

LRMC пересекает LAC в минимумеLRMC crosses LAC at its minimum.

7. Большая идея Frank: форма LAC → структура отрасли

Форма LAC предсказывает, сколько фирм будет в отрасли (p. 286).

The shape of LAC predicts industry structure — the big idea of Chapter 9.

LACRTS / scaleОтрасльПримеры (Frank)
↓ падаетIncreasing · economiesМало крупных · natural monopolyЭлектричество, вода, газ
↑ растётDecreasing · diseconomiesМного мелких фирмСалоны, рестораны, мастерские
— плоскаяConstantМелкие и крупные вместеМногие «обычные» отрасли

Falling LAC → one big firm beats rivals on cost → monopoly. Rising LAC → many small firms. Flat → size doesn't matter.

→ Monopoly & natural monopoly (Ch. 11)

9. Ловушки на экзамене

RTS ≠ diminishing returns. RTS = удвоил всё (LR). Diminishing returns = +1 worker при фикс. K (SR).

LAC = LRAC = LTC ÷ Q. LRTC начинается из (0,0) — в LR нет FC.

Оптимум: MPL/w = MPK/r, не «максимум выпуска».

LAC — envelope SAC снизу; каждая SAC касается LAC в одной точке.

Don't confuse RTS with diminishing returns. LAC = envelope of SAC from below. Optimum = cost minimization, not output maximization.

10. Шпаргалка Ch. 9
