Intertemporal Choice — Межвременной выбор

consumption bundles · intertemporal budget constraint · present & future value

1. Intertemporal consumption bundles / Межвременные наборы

Межвременной набор — комбинация текущего потребления C₁ и будущего потребления C₂. Каждая точка на графике — один возможный вариант «сколько тратить сейчас vs потом».

Intertemporal consumption bundles show combinations of current consumption (C₁) and future consumption (C₂). Each point on the graph is one possible combination.

  • Потребляешь меньше сегодня → можешь потреблять больше завтра (save)
  • Потребляешь больше сегодня → будешь потреблять меньше завтра (borrow)

If people consume less today, they can consume more in the future. If they consume more today, they consume less in the future.

Каждая точка = один набор (C₁, C₂): сколько тратим сейчас и сколько остаётся на будущее.Each point is one bundle of current consumption C₁ and future consumption C₂.

2. Intertemporal budget constraint / Межвременное бюджетное ограничение

IBC показывает, как люди распределяют деньги между «сейчас» и «потом» — сколько тратить и сберегать во времени.

The intertemporal budget constraint shows how people choose to spend and save money over time.

СимволSymbolЗначениеMeaning
C₁Потребление в период 1 (сегодня)Current consumption
C₂Потребление в период 2 (будущее)Future consumption
M₁Доход в первом периодеIncome in period 1
M₂Доход во втором периодеIncome in period 2
rСтавка процента («цена времени»)Interest rate
C₁ + C₂/(1+r) = M₁ + M₂/(1+r)
Наклон линии = −(1+r) · Точка E = (M₁, M₂) — endowment (наделённость): тратим ровно свой доход, без займа и сбережений

Slope = −(1+r). Point E = (M₁, M₂) is the endowment point, where the person spends exactly their income each period.

Наклон −(1+r) означает: если потратить +1€ сегодня, придётся отказаться от (1+r)€ завтра. Линия наклонена вниз, потому что больше потребления сегодня = меньше потребления в будущем.

Slope = −(1+r): spending 1€ today leaves you (1+r)€ less in the future. The budget line is downward sloping because consuming more today means consuming less in future.

Ось X = C₁ (сейчас), ось Y = C₂ (будущее). Наклон −(1+r). E = endowment.Vertical intercept = max future consumption if all income saved; horizontal = max current consumption if all future income borrowed.

  • Верхняя точка (C₁ = 0): max future consumption — всё сберегли, получаем M₂ + M₁(1+r)
  • Правая точка (C₂ = 0): max current consumption — весь будущий доход заняли и потратили сегодня

Top point shows maximum future consumption if all income is saved. Right point shows maximum current consumption if all future income is borrowed and spent today.

3. Present value / Приведённая (текущая) стоимость

Present value (PV) — стоимость будущих денег сегодня. Будущие деньги «дисконтируем», делим на (1+r).

Present value is the value of future money today.

PV = FV / (1+r)ⁿ
Пример IBC: C₁ = M₁ + M₂/(1+r) — весь будущий доход, приведённый к сегодня

PV = FV / (1+r)ⁿ. n = number of periods. Future money is worth less today because of interest.

4. Future value / Будущая стоимость

Future value (FV) — стоимость сегодняшних денег в будущем. Сегодняшние деньги растут на (1+r).

Future value is the value of today's money in the future.

FV = PV × (1+r)
Пример IBC: C₂ = M₂ + M₁(1+r) — весь текущий доход, перенесённый в будущее

FV = PV × (1+r). Today's money grows with interest.

ОбозначениеSymbolЗначениеMeaning
FVFuture value — будущая стоимость
PVPresent value — текущая стоимость
rInterest rate — ставка процента
  • Сберегаешь сегодня → потребляешь больше в будущем (за счёт процентов)
  • Занимаешь сейчас → тратишь больше сейчас, но меньше потом

If people save today, they can consume more in the future because of interest. If they borrow now, they can spend more now but less later.

5. Числовой пример / Numerical example

Дано: M₁ = 2500€, M₂ = 4200€, r = 20% → (1+r) = 1,2

PV дохода: C₁ + C₂/1,2 = 2500 + 4200/1,2 = 2500 + 3500 = 6000€

FV дохода: 2500 × 1,2 + 4200 = 3000 + 4200 = 7200€

Наклон линии: −(1+r) = −1,2

max C₁ = 6000 (всё сегодня) · max C₂ = 7200 (всё в будущее) · E = (2500, 4200)

With M₁=2500, M₂=4200, r=20%: PV of income = 6000, FV = 7200, slope = −1.2.

Bundle = (C₁, C₂) · IBC: C₁ + C₂/(1+r) = M₁ + M₂/(1+r) · slope = −(1+r) · E = (M₁,M₂) · PV = FV/(1+r) · FV = PV(1+r)

Key: intertemporal bundle, budget constraint, slope −(1+r), endowment E, present and future value formulas.

Межвременной выбор: как распределить потребление между «сейчас» (C₁) и «потом» (C₂). Ставка r связывает периоды: PV дисконтирует будущее, FV наращивает настоящее. Наклон бюджетной линии = −(1+r).

Intertemporal choice allocates consumption between present and future. The interest rate links periods via present and future value. Budget line slope = −(1+r).
