Vue vs Angular — Interview Prep

Шпаргалка под собес: отличия, особенности Vue и ответы одним абзацем. Для тех, у кого база Angular.

Главные отличия

Angular Vue
Философия Полноценный фреймворк (opinionated) Библиотека + экосистема (гибче)
Язык Почти всегда TypeScript JS или TS (на выбор)
Структура .ts + .html + .scss + декораторы SFC .vue = template + script + style
Реактивность Zone.js / signals Proxy: ref / reactive (Vue 3)
DI Встроенный DI-контейнер Нет классического DI → provide/inject, composables
Роутинг / store Router + NgRx / Signals vue-router + Pinia
Сборка Angular CLI / esbuild Часто Vite
Формы Reactive Forms / signal forms — мощно для enterprise v-model проще; сложные формы — вручную / библиотеки

Особенности Vue (что объяснить на собесе)

1. Реактивность (Vue 3)

ref / reactive → Proxy. Меняешь данные — UI обновляется.

«В Vue реактивность явная через ref/reactive; в Angular — change detection / signals».

2. Composition API vs Options API

Options: data, methods, computed — проще новичкам.

Composition (setup / <script setup>): логика по фичам, ближе к hooks, чем к Angular-классам.

3. SFC

Один файл .vue: template + script + scoped CSS. В Angular обычно три файла + декораторы.

4. Директивы

v-if, v-for, v-model, v-show, v-bind.

Angular: *ngIf / @if, *ngFor / @for, [(ngModel)], [prop], (event).

5. Стейт и DI

Глобальный стейт — Pinia. Локальный шаринг — provide / inject и composables useXxx.

В Angular — сервисы + providedIn: 'root'.

6. Экосистема

Vue легче войти, но стек выбираешь сам (Pinia, Router, тесты, UI-kit). Angular даёт структуру «из коробки» — плюс для enterprise.

Шпаргалка Angular → Vue

@Input() → defineProps
@Output() → defineEmits
ngOnInit → onMounted
ngOnDestroy → onUnmounted
service + DI → composable / Pinia
async pipe + Observable → ref + async/await
*ngFor trackBy → :key в v-for
lazy routes → async components + vue-router

Топ Q&A (ответ в 1–2 предложения)

ref vs reactive?
ref — для примитивов и любого значения (доступ через .value). reactive — для объектов; удобнее деструктуризации через toRefs.
computed vs watch / watchEffect?
computed — производное значение с кэшем. watch — реакция на конкретный источник. watchEffect — сам трекает зависимости и сразу запускается.
v-if vs v-show?
v-if монтирует/удаляет из DOM. v-show только CSS display — лучше при частых переключениях.
Lifecycle: аналог ngOnInit / ngOnDestroy?
onMounted и onUnmounted (в Composition API). Также есть onBeforeMount, onUpdated и др.
Props / emits / v-model на компоненте?
Вход — defineProps, события — defineEmits. v-model на ребёнке = prop modelValue + emit update:modelValue (или именованный v-model).
Pinia?
Store: state, getters, actions. Проще и легче NgRx; нет лишней boilerplate-магии для типичных SPA.
Почему Vue 3 быстрее Vue 2?
Proxy вместо Object.defineProperty, лучше tree-shaking, Fragments, Teleport, более эффективный runtime compiler.
Как не дёргать UI лишний раз?
Правильные ключи в списках, computed вместо тяжёлой логики в template, при больших объектах — shallowRef / markRaw где нужно.
Scoped styles?
<style scoped> добавляет уникальные атрибуты — стили не текут наружу. Альтернатива — CSS modules.
SSR / Nuxt?
SSR рендерит HTML на сервере (SEO, первый paint). Nuxt — meta-фреймворк вокруг Vue: роутинг, SSR/SSG, conventions.
